# Flask Dictionary App

A dictionary web application built with **Flask**, **MySQL**, **Bootstrap 3.4.1**, and **jQuery 3.7.1** as part of the Backend Python Developer programme on [Startocode](https://startocode.com).

## Features

- **Home Page** — Search for a word and retrieve its meaning from a MySQL database.
- **Dashboard Page** — Full CRUD operations for managing dictionary entries.

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Backend | Flask (Python) |
| Database | MySQL (`flaskext.mysql`) |
| Frontend | Bootstrap 3.4.1 |
| Interactivity | jQuery 3.7.1 |

## Validation

- **Client-side:** HTML form attributes
- **Server-side:** Python conditionals
- **Feedback:** Flask flash messages for success and error states

## Pages

| Page | Purpose |
|------|---------|
| Home | Search a word → return definition from DB |
| Dashboard | Create, Read, Update, Delete dictionary entries |
